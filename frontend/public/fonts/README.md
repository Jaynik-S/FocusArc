# Self-hosted fonts

- Fraunces variable TTF (weight, optical size, softness and wonk axes): unmodified official Google Fonts binary, https://github.com/google/fonts/tree/main/ofl/fraunces. Downloaded 2026-10-26. Headings use softness 55 and wonk 1; the adjacent `fraunces-OFL.txt` supplies its license.
- Nunito Sans Latin variable WOFF2 (weights 400–700): official Google Fonts CSS API, `fonts.gstatic.com/s/nunitosans/v19/`. Original project: https://github.com/google/fonts/tree/main/ofl/nunitosans

Font binaries are unmodified and served locally; no runtime font-service requests are made. Both use the SIL Open Font License, provided in the adjacent OFL files. Bree Serif files are retained as the preceding design's reference and are no longer loaded by the application.
