# Interface material

`gouache-paper.webp` is a neutral grayscale material generated with the built-in image generation tool on 2026-10-26 (America/Toronto). It supplies fine paper tooth and quiet painted variation to normal UI surfaces through soft-light blending. It contains no screensaver scene or objects and does not choose a course color.

The generated PNG was losslessly encoded to WebP with FFmpeg. Decoded RGBA frame hashes were verified identical; delivery size decreased from 3,032,613 to 1,879,550 bytes. The original generated PNG remains outside the shipping asset directory. No pixels were edited.

The exact generation prompt is in `gouache-paper.prompt.txt`. Impeccable records it in `gouache-paper.webp.json`, its supported sidecar fallback for WebP. Its provenance scan reports no missing records. Surface roles are documented in `DESIGN.md`.
